# Image classification

## Task

Given an image, the model predicts one category label from a fixed set.
We study image classification only; image generation and chatbot dialogue are outside the scope.

## Evaluation

For each model, we report classification accuracy.
We also report accuracy separately for each category.
We focus on image classification, rather than generating images or building a chatbot.
This work should not be understood as an image generator or a chatbot.
